EARN-VAULT

Earn Vault is a beginner Python project created to practise programming concepts.

FEATURES
-Simulated money balance
-Job system for earning virtual money
-Market for purchasing virtual items
-Account information

TECHNOLOGIES
-Python

PROJECT STATUS
Work in progress. Features may be incomplete as I continue learning Python.

HOW TO RUN
1. Install Python 3.
2. Download or clone this repository.
3. Run the Python file using your Python interpreter.
